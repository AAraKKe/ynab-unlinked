`yul load` now identifies transactions by YNAB's own import id convention (`YNAB:<milliunits>:<date>:<occurrence>`) and lets YNAB do the matching against transactions you entered yourself. The local date, amount and payee matcher, the partial-match prompt and the payee rename rules are gone; two identical purchases on the same day now import as two transactions, transactions already in YNAB are dimmed instead of re-sent, and anything YNAB rejects as a duplicate is reported. The config moves to V3, dropping payee rules and per-entity checkpoints.
