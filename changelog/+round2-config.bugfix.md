The CLI no longer undoes settings the app saved while a command was running, `yul config set budget` clears the old budget's banks, accounts, debt mappings and reconciliation date like the app does, YNAB and network errors print one line instead of a traceback, `yul setup` asks before replacing an existing config (`--yes` skips the question), a run with `YUL_HOME` keeps its token in a keychain item of its own, payees longer than YNAB's 200 characters are cut instead of failing the whole file, and the configs a migration writes on the way are readable by you only.
